# Project context memory

- On **every task**, start by reading `docs/project-context.md` to load the latest state, findings, and reasoning from previous chats.
- On **every task**, before finishing, update `docs/project-context.md` with your overall observations, findings, and reasoning from this task.
- `docs/project-context.md` must always reflect the **latest state** of the project and of the current conversation. It is a living document that is **constantly updated** — replace stale information instead of appending indefinitely.
- Record at minimum: key decisions and *why*, the current state of work in progress, open questions, gotchas, and anything the next chat would need to continue without re-deriving context.
- Keep it focused, accurate, and current. If the document is missing or empty, create/seed it with a concise summary of the repo's current state.
